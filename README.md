# tmalone.dev

Tyler Malone's personal site. One page, plain HTML and CSS, no build step.

```
index.html   the page
styles.css   two inks on paper (light), ContraptionSoft charcoal (dark)
404.html     not-found page
```

Run locally: `python3 -m http.server 8000`, then open http://localhost:8000.

Deploy: static on Vercel. No framework, no build command, output directory is the repo root.

The previous space-to-ocean scroll site (games, music player, leaderboard API) is in the git history; its last state is master at 68f1c71.
